# Third-Party Notices

This repository is public, so every committed asset must be redistributable. Permitted sources are
assets created for DropProtocol, assets whose license explicitly permits redistribution, and CC0
assets.

Every external asset must be recorded here with its name, creator, source, and license **before**
it is committed.

Unity packages resolved through the Unity Package Manager are not vendored into this repository;
they are declared in `Packages/manifest.json` and are governed by the
[Unity Package Distribution license terms](https://unity.com/legal/licenses/unity-companion-license).

## Explicitly excluded

- Raw Unity Asset Store content whose license does not permit redistribution.
- Raw Mixamo character or animation files.
